# Orr Technologies — Small Business Website Design

Source for the Orr Technologies marketing site: custom websites for small
businesses, built in about two weeks, delivered to the client's own GitHub.

- Canonical: https://orrtechnologies.vercel.app (override with `NEXT_PUBLIC_SITE_URL`)
- Stack: Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Postgres (drizzle-orm) · Bitcoin settlement

## Getting started

```bash
npm install
cp .env.example .env.local   # optional — the site renders without a database
npm run dev                  # http://localhost:3000
```

Without `DATABASE_URL` the public pages fall back to the static plan catalog
in `src/lib/content.ts`; leads, orders, forge builds and the console need a
real Postgres connection.

## Scripts

```bash
npm run dev         # dev server
npm run build       # production build
npm run start       # serve the production build
npm run lint        # eslint
npm run typecheck   # tsc --noEmit
```

## SEO system

Search visibility is a first-class feature, not an afterthought:

- **Canonical origin** — `NEXT_PUBLIC_SITE_URL` (falls back to
  `https://orrtechnologies.vercel.app`). All canonicals, sitemap entries and
  JSON-LD URLs derive from `src/lib/seo.ts`, so there is one source of truth.
- **Metadata** — `src/app/layout.tsx` holds the title template, description,
  keywords, Open Graph, Twitter cards and Googlebot directives. Every
  indexable route exports its own canonical, title and social image.
- **Structured data** — `src/lib/seo.ts` builds the schema graph: organization
  and WebSite sitewide; `Service` + `OfferCatalog` + `FAQPage` on home and
  pricing; `CollectionPage` + `ItemList` on the blog; `BlogPosting` and
  `BreadcrumbList` on each guide; `WebApplication` on Forge Studio. Only
  content that actually renders is marked up.
- **Sitemap & robots** — generated by `src/app/sitemap.ts` and
  `src/app/robots.ts`. `/studio` is included; `/checkout` and `/console` are
  `noindex`, and `/console` + `/api/` are disallowed.
- **Feed** — `src/app/feed.xml/route.ts` publishes RSS 2.0 for the blog.
- **Media** — `public/media/forge-hero.jpg` is the 1200×630 Open Graph image;
  work and guide art live beside it.
- **Fonts** — self-hosted through `next/font` (no render-blocking Google Fonts
  request, no third-party font privacy leak).

## Deployment

Any Node host works (Vercel, Netlify, Fly). Set `DATABASE_URL` in the host
environment to activate the data layer, and `NEXT_PUBLIC_SITE_URL` if the site
is served from a different canonical origin. `next build` succeeds without
either.

The older Netlify deployment of this site is not the canonical copy. Retire it,
or point it at the same domain, so search engines only see one version.
