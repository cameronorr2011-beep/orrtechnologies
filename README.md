# Orr Technologies

**Technology for what comes next.**

Single-page marketing site for Orr Technologies — software, applied AI, biological systems, and advanced hardware.

## Stack

Plain HTML + CSS + a few lines of vanilla JS. No build step, no dependencies (Google Fonts is the only external request).

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Deploy (GitHub Pages)

Repo: https://github.com/cameronorr2011-beep/pixelatedlabs

1. Push this folder to the repo (main branch).
2. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
3. Site goes live at `https://cameronorr2011-beep.github.io/pixelatedlabs/`.

## Brand reference

- Palette: `#080A0C` black · `#F2F3F4` off-white · `#8B929B` muted gray · celadon accent `#7FB8A4`
- Wordmark: geometric `ORR` + letter-spaced `TECHNOLOGIES` subline (pure text, no image)
- Feel: technical, scientific, restrained, trustworthy
